# Raffaella Story 6

Invitación independiente basada en la web original de Canva.

## Desarrollo

`npm install` y `npm run dev`.

## Validación

`node --test tests/*.test.mjs`

`npx tsc --noEmit`

`npm run build`

## Música

El MP3 proporcionado por el usuario se reproduce sin video. El reproductor rosa controla play/pausa y muestra progreso del mismo audio que intenta autoplay al entrar. Un toque real en la portada reintenta si el navegador exige interacción. La pausa manual se respeta.

## Datos

26 de septiembre de 2026, 3:00 p. m., hora de Lima. Se corrigió el contador original que apuntaba a las 6:00 p. m. Las imágenes proceden del sitio indicado por el usuario, se almacenan localmente en formato WebP y el formulario, Maps y regalos mantienen los enlaces originales.
